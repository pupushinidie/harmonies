## 1. 风格

| 项 | 规定 |
|---|---|
| 基调 | 暖灯下的木纹桌面上摆着一盒绘本风的木头桌游：厚实的彩色木圆片、蜂窝形木版图、绘本里的小动物。夜间版（默认）是台灯照着的深色胡桃木桌，白天版是窗边日光下的浅橡木桌。版图、标记、卡面在两种主题下用**同一套图** |
| 光照 | 所有小图统一**左上方来光**：圆片顶面左上 1px 亮边、侧面右下更暗；摞的下面有一块半透明的影子（已画在标记图里）。场景主光：夜里左上角台灯的暖黄光池，白天是左上窗户的日光 |
| 描边 | 标记、方块、图标一圈 1px 深棕描边 `#2a1c14`（不用纯黑）。动物立绘不描外框（卡框由界面画）。场景不描边 |
| 像素密度 | 六边形格子 32×28 原图：自己的版图桌面 **3×**（96×84）、手机 **2×**；对手版图 1× 或 2×。动物立绘 64×64：桌面 2×、手机/小卡 1×。图标 16×16 / 24×24：1×–3× |
| 文字 | **所有图里一个字、一个数字都不要**：卡上的图案、分数表、方块数、终局分数全部由界面用代码叠上（见第 4 节）。界面里不出现「Harmonies」 |
| 不要 | 照搬原版 Harmonies 的插画、版图和卡面；像名人或知名角色的动物（迪士尼、宝可梦、彼得兔、狐狸先生之类：动物一律不穿衣服、不拿道具）；人物；像国旗的旗帜 |

## 2. 素材清单

「来源」：**PixelLab** = 出候选、自查后挑定；**代码** = `art/*.py` 画（需要精确几何的格子、圆片、高亮、特效）；**代码+PixelLab** = 代码合成 PixelLab 的图。
「夜/日」：**同** = 一张图两种主题都用；**分** = 夜间、白天各一张。

### 2.2 个人版图（格子几何是硬规定，开发按这个公式映射坐标）

**六边形格子**：平顶，32×28 像素。格子 `(c, r)`（§2.3 的列、行，都从 0 开始）在版图图片里的左上角：

```
x = OX + 24·c
y = OY + 28·r + (c 是奇数 ? 14 : 0)
格子中心 = (x + 16, y + 14)
```

列距 24、行距 28，奇数列低半格（14）。相邻格子正好拼满，没有缝。格子的像素形状见 `board/hex-mask.png`（白色 = 格子内）。

### 2.3 地貌标记（每一种合法的摞一张图）

每张 32×44，**格子中心对准图里的 (16, 32)**：放在格子 (c, r) 上时，标记图左上角 = 格子左上角 + (0, −18)。按格子中心的 y 从小到大画（下面的格子后画，盖住上面格子伸上来的部分）。

每层圆片厚 5px（3× 时 15px），层与层之间有 1px 深色缝，侧面数得出层数；树冠和房屋是顶上的「帽子」，不算层；田是黄圆片顶面画一行行麦穗。高度怎么读：树 = 棕圆片数 + 1，山 = 灰圆片数，房屋 = 它下面压着的那一片。
